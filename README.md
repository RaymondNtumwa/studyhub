
# StudyHub (SRIP)

> Your academic resources, in one place.

## Overview

StudyHub is a responsive Student Resource Information Portal
designed to centralise academic resources, educational platforms
and university-related information within a single accessible
web interface.

The project is being developed as part of the Software Project
Management practical examination at Uganda Christian University.

## Project Objectives

- Centralise useful and verified academic resources.
- Simplify access to educational platforms.
- Provide efficient resource search and category filtering.
- Ensure accessibility across desktop and mobile devices.
- Demonstrate practical software project management principles.

## Planned Features

- Professional and responsive homepage.
- At least 15 verified educational resource links.
- Academic resource categorisation.
- Functional search and category filtering.
- Clear navigation.
- Contact and feedback information.
- Public website deployment.

## Local Installation

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using a web browser or Live Server.

No external dependencies or database installation are required.
